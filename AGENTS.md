# Agent Entrypoint

This is a small Vue 3 + Vite interview task for a Wiki Knowledge Graph UI. Keep changes scoped and avoid adding process-heavy structure.

## Start Here

- Read `README.md` for the task requirements and delivery rules.
- Read `ARCHITECTURE.md` for the current code map.
- Read `docs/INDEX.md` for the small docs hub.
- Use `docs/quality.md` before claiming a task is ready.

## Commands

- Install dependencies: `npm install`
- Run locally: `npm run dev`
- Production build: `npm run build`

There is no package script for tests or linting right now. Do not invent commands.

## Repo Rules

- Do not change `src/data/mock.js`; the task says mock data must stay untouched.
- Record process, AI tool use, library justification, and feedback in `TASK.md` when doing the interview tasks.
- Each task should be committed separately with a descriptive message.
- If adding a dependency, justify it in `TASK.md` and keep it aligned with the README task.
